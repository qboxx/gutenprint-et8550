# Afla_books six-channel print-to-qbox calibration — future-extension PRD

> **Status:** Future ET-8550 extension only. No print candidate is authorised by this document.
>
> **Scope correction — 2026-07-16:** The active project is the current ET-2856 four-channel normal-colour RGB/JPEG calibration loop documented in `docs/AFLABOOKS-FOUR-CHANNEL-RGB-JPEG-CALIBRATION-PRD.md`. The ET-8550 normally expects PB and GY; a later conversion may use UV cyan and UV yellow, but that mapping and work are out of scope here.
>
> **Future outcome:** A reproducible extension that converts an Afla_books visual/UV target into a measured six-reservoir print, captures it in qbox10, measures the result, and safely improves the next print.

## 1. The mission

Afla_books needs to decide **where** ink is applied and **how much of each reservoir** is applied. The process is deliberately iterative:

```text
defined target + six-channel coverage raster
→ frozen print pipeline
→ physical printed sheet
→ qbox10 White and UV captures
→ registration + per-patch/per-region measurements
→ constrained model update
→ next candidate raster
```

The result is not a one-off attractive chart. It is a reusable system that can be run again after media, ink, printer, or qbox changes.

### Current and future hardware roles

| Platform | Reservoirs being calibrated | Role |
|---|---|---|
| Current Epson ET-2856 proof printer | C, M, Y, K | Prove the qbox10 measurement, audit, reporting, and iterative-update software. It is **not** a source of transferable six-channel coefficients. |
| Future Epson ET-8550 | BK, C, M, Y, GY, PB | Future platform. It normally expects grey (`GY`) and photo black (`PB`). A later UV-yellow/UV-cyan conversion must be separately specified and re-characterised. |

The existing ET-8550 raw diagnostic record establishes the normal physical raw-channel order:

```text
raw stream index:  0   1  2  3   4   5
physical channel: BK   C  M  Y  GY  PB
```

The calibration source and the raw transport must **not** be confused. The normal six-reservoir source/model order is deliberately:

```text
u_source = [C, M, Y, BK, GY, PB]
u_raw    = [BK, C, M, Y, GY, PB]
```

Any future UV conversion must declare its own source labels, physical reservoir mapping, material compatibility record and decoded-stream proof. It must not inherit assumptions from normal GY/PB ink.

## 2. Required control boundary

We control **coverage fields and masks**, not individual droplets in the first implementation.

For every source location `x, y`, a future six-reservoir job will use a six-element coverage vector in the normal source order:

```text
u(x,y) = [C, M, Y, BK, GY, PB]  where each channel is in [0, 1]
```

If UV inks are later introduced, the final two labels and their physical reservoir mapping must be explicitly versioned; they are not part of the active four-channel implementation.

- The calibration system chooses coverage values per patch/region and produces six explicit raster planes.
- A frozen, audited Gutenprint/raw pipeline converts those planes into the printer’s halftone and droplet pattern.
- The printer/driver halftoning is therefore part of the calibrated system and must be versioned and held constant.
- The system must never rely on ordinary RGB application printing to decide where UV ink appears. A normal RGB driver may use PB/GY wherever it chooses; after those reservoirs contain UV ink, that would create uncontrolled UV placement.

The existing four-channel Windows-rendered ET-2856 sheet is useful only as a camera/measurement experiment. It is **not** a direct-six-channel ink-control path. Likewise, the old `TAC ≤ 192` and `K ≤ 64` limits are four-channel experimental bounds, not six-channel physical safety limits.

### Print-contract gate

Before a physical calibration chart may be printed, the run must record and audit:

- printer model, firmware, reservoir-to-logical-channel map, ink batch and media;
- source raster format, channel count/order, dimensions, resolution and SHA-256;
- Gutenprint revision, printer definition, all print options, dithering, colour correction and raw-stream decoder result;
- exact printer spool hash and decoded channel-plane verification;
- a dry/diagnostic test proving that any future converted spot channels appear only in their approved masks;
- no scaling, driver colour conversion, or automatic RGB separation.

Raw LPR transmission of TIFF/PNG/PDF bytes is forbidden. A file is not a printer language merely because its pixels have CMYK values. The raw print stream must be generated by the supported Gutenprint path and decoded/audited before submission.

## 3. Measurement contract

Each printed calibration sheet is placed in qbox10 and captured with immutable settings for the whole calibration series.

### Captures

| Capture | Purpose |
|---|---|
| White illumination RAW/DNG + derivative | Visible colour, density/opacity, bleed, gutter contamination and interior uniformity |
| UV illumination RAW/DNG + derivative | Future-only capture for the later two converted spot inks, their bleed and their interaction with visible inks |
| Dark/flat references | Correct camera noise and field illumination before comparison |

Every capture records qbox ID, camera settings, lens position, LED setting, dark/flat IDs and file hashes. Fiducials register the page before any patch is measured. A report must state whether all four were observed or whether a validated three-corner parallelogram inference was used.

### Per-patch measurement vector

For patch `p`, the measurement vector is:

```text
m_p = [visible_colour, visible_saturation, visible_hue,
       visible_opacity, visible_uniformity,
       visible_absolute_gutter, visible_relative_bleed,
       UV_signal, UV_uniformity, UV_absolute_gutter, UV_relative_bleed]
```

`UV_signal` must be defined from the intended Afla_books use case before optimisation (for example, camera response above locally measured blank paper under the locked UV light). It must not be guessed from visible RGB.

The target vector `m*_p` states the required visible appearance and UV response. Blank gutters, fiducials and page margins are immutable control regions.

## 4. Chart design

The next chart/master geometry is a **centred 160 × 160 mm active target** on A4. The target and fiducials are deliberately inset so that trimming and qbox placement leave a meaningful frame margin.

The calibration design is not an exhaustive six-dimensional grid. It contains:

1. **Spatial repeat controls** — blank paper, neutral/density controls, visible primaries and UV-only controls repeated across the page to estimate qbox and print variability.
2. **Single-channel ramps** — BK, C, M, Y, GY and PB at safe coverage levels to learn normal six-reservoir response; any later converted spot channels receive a separately designed chart.
3. **Relevant interaction patches** — visible pairs and UV/visible interactions, especially the UV masks used by Afla_books.
4. **Stratified all-channel samples** — a deterministic space-filling design inside measured safe limits; it is expanded only where data show uncertainty.
5. **Held-out patches** — never used to fit the update model; they decide whether an iteration actually improved.

The physical safety region is learned from measurements. It has per-channel, mixture-specific and local limits; it is not a single universal total-ink cap.

## 5. Calibration model and update rule

### Model choice

A classical Neugebauer/Yule–Nielsen model is useful as a visible-printing baseline: it models the reflectance of halftone colourants from measured primary/overprint states and a fitted optical-dot-gain parameter. It is insufficient as the final Afla_books model because two UV inks, fluorescence, qbox camera response, bleed and texture are not fully described by visible reflectance alone.

Research basis for using it only as a baseline:

- Hersch, *Spectral Neugebauer-based color halftone prediction model accounting for paper fluorescence* (2014), DOI [`10.1364/ao.53.005380`](https://doi.org/10.1364/ao.53.005380).
- Chen, Berns and Taplin, *Six Color Printer Characterization Using an Optimized Cellular Yule-Nielsen Spectral Neugebauer Model* (2004), DOI [`10.2352/j.imagingsci.technol.2004.48.6.art00009`](https://doi.org/10.2352/j.imagingsci.technol.2004.48.6.art00009).
- Rossier and Hersch, *Calibrating the ink spreading curves enhanced Yule-Nielsen modified spectral Neugebauer model with the two-by-two dot centering printer model* (2009), DOI [`10.1117/12.804818`](https://doi.org/10.1117/12.804818).

These models motivate the experimental design; they do not remove the need to measure the actual Afla_books inks, paper, qbox camera, and printer pipeline.

The production update model is therefore an empirical, regularised local response surface fitted from physical prints:

```text
m_hat(u) = B × phi(u)
phi(u) = [1, u_i, u_i², u_i×u_j for approved i,j interactions]
```

where `u` is the six-channel coverage vector and `m_hat` predicts the White/UV measurement vector. Robust fitting and repeat controls estimate uncertainty; interaction terms are retained only when physical measurements support them.

### Candidate step

For each patch/region, the next coverage is a damped constrained Gauss–Newton step:

```text
u_next = Project_safe(
  u_now - alpha × (Jᵀ W J + lambda I)^(-1) × Jᵀ W × (m_hat(u_now) - m_target)
)
```

where:

- `J` is the local derivative of the fitted response model with respect to the six ink coverages;
- `W` weights the visible and UV target errors for that patch;
- `alpha` is a small measured trust-region step, not an unrestricted correction;
- `lambda` prevents unstable updates;
- `Project_safe` enforces coverage ranges, learned mixture limits, approved UV masks, and non-regression limits for bleed, opacity and uniformity.

This formula is a decision rule, not a claim that the camera knows individual droplets. It tells us whether to increase or decrease a particular reservoir’s coverage in a particular region, then asks the physical printer/qbox loop to verify the prediction.

### Release rule

A candidate may be printed only when all of the following pass with uncertainty margins:

- visible colour, saturation and hue improve on held-out targets where they are in scope;
- UV signal improves or meets its target on held-out UV patches;
- no material regression in absolute gutter contamination, relative bleed, opacity or interior uniformity;
- all six channels remain inside their measured safe domain;
- UV ink is exactly zero outside approved UV masks;
- the complete print/capture/model/report provenance is present.

If the evidence is inconclusive, the outcome is `REJECTED — NO PRINT`, not a relaxed threshold.

## 6. Reproducible run record

Each run is an immutable directory and manifest with this state machine:

```text
DRAFT
→ PREPRINT_AUDITED
→ PRINT_SUBMITTED
→ PHYSICALLY_CONFIRMED
→ CAPTURED
→ REGISTERED
→ ANALYSED
→ CANDIDATE_ONLY
→ HELD_OUT_VALIDATED
→ AUTHORISED or REJECTED
```

Required artifacts:

```text
run-manifest.json          printer/ink/media/qbox settings and hashes
source-six-channel.*       source raster and plane audit
printer-spool.*            generated raw spool and decoded channel audit
white/ and uv/             DNG/JPEG captures plus dark/flat references
registration-overlay.*     visual proof of patch alignment
patch-report.json          every measurement and uncertainty interval
model.json                 fitted response model and version
candidate.*                present only after candidate gates pass
decision.json              explicit authorisation or rejection reasons
```

## 7. Phased delivery

### Phase A — current ET-2856 (four channels)

- Freeze a safe print route and prove the qbox10 White/UV measurement/reporting loop.
- Build the reusable registration, local paper normalisation, bleed, opacity and uniformity logic.
- Treat the four-channel coefficients as **non-portable**; they validate the software and experiment design only.

### Phase B — ET-8550 before UV conversion

- Verify the existing six-channel raw mapping and raw-spool decoder using known compatible inks/media.
- Capture baseline behaviour of all six physical channels.

### Phase C — ET-8550 after a separately approved UV-yellow/UV-cyan conversion

- Complete ink/material compatibility, flushing and hardware safety sign-off separately.
- Declare the exact physical reservoir mapping before the first converted-ink chart.
- Re-run channel mapping and low-coverage diagnostic charts from zero.
- Build the six-channel response model from new physical evidence; do not reuse Pigmera/stock-Epson coefficients.
- Run held-out validation before using the result for Afla_books printing.

## 8. Non-negotiables

- No uncontrolled RGB printing for UV work.
- No raw LPR file passthrough.
- No silent replacement of the channel order, printer options, media or camera settings.
- No claim of absolute colour accuracy without a spectrophotometric reference chain.
- No print merely because a model prediction looks favourable.
- No UV coverage outside declared masks.

## 9. Current disposition

The earlier Windows-rendered 4-channel validation remains a useful measurement experiment, but it does **not** authorise a calibration master and does **not** establish six-channel UV ink placement. The next engineering task is to implement this PRD’s print-contract and six-channel response-model interfaces in the existing `tools/et8550/printer_calibration/` system.
